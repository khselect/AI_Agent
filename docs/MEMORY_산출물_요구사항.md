# 산출물 작성 요구사항 (메모리 노트)

_기록일: 2026-08-07 · 프로젝트: 철도안전 AI 에이전트_

> 이 파일은 프로젝트 메모리에 반영할 표준 요구사항입니다. 세션 메모리 파일이 읽기 전용이라
> outputs에 남깁니다. 프로젝트 지식(memory.md)에 병합해 두면 이후 세션에도 유지됩니다.

## 기본 산출 형식 (Default)

- **모든 인사이트/분석은 인터랙티브 코드로 작성된 `.html` 파일로 생성한다.**
  - 자체 완결형(standalone) — 브라우저에서 바로 실행.
  - 라이트/다크 모드 대응(CSS 변수).
  - 슬라이더·토글·스텝퍼 등 인터랙티브 요소를 유효한 곳에 포함.
  - outputs 폴더에 저장 후 파일 카드로 제시.

## 요청 시 추가 형식 (On request)

- **Markdown(`.md`)** — 기술 사양·문서.
- **Word(`.docx`)** — 내부 이해관계자용, 한국 정부 보고서 형식(구조화·표 중심·격식 문체).

## 형식 선택 기준

| 대상/목적 | 형식 |
|---|---|
| 인사이트·분석·설명 (기본) | 인터랙티브 HTML |
| 기술 사양·명세 | Markdown |
| 내부 보고·제안 | DOCX |
